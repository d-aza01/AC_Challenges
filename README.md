# AC Challenges

Welcome to AC Challenges!

This repository is a collaborative space for weekly Data & Analytics challenges.

The goal is to practice and improve skills such as:

- Python
- Pandas
- Jupyter Notebooks
- Data manipulation
- Data analysis
- Git & GitHub
- Pull Requests
- Code Reviews

## How It Works

Each week, a new data challenge will be published in this repository.

Participants will work on their own solutions and submit their work through a Pull Request.
